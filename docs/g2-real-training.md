# G2 real SiLRI training: operator runbook

This procedure is for a separately commissioned setup. Software completion does **not** approve robot motion. The hardware emergency stop must remain independent of the Actor, Learner, clock monitor, and host process.

1. Verify the physical E-stop works, identify the person who owns it, and establish an exclusion zone before powering or enabling the robot. Keep all personnel outside the swept workspace.
2. Start `clock_monitor` in its own foreground terminal. Use its configured clock socket and explicit expected master; inspect live healthy snapshots and stop if master, camera, robot-state, or transform freshness changes. The Actor cannot start the monitor for you.
3. After all independent field gates have separately passed, copy the read-only template to a new owned private configuration file. Fill the measured workspace bounds, motion scales, clock socket/master, approved commissioning profile, and all four evidence paths and SHA-256 hashes. Independently verify camera/state/transform freshness, XYZ and RPY direction and scale, software stop and lease expiry, hardware E-stop, and the physical exclusion zone. Set `requested_motion` true only for that approved copy, and keep its `mode` as `train`. Start the Learner with **that final configuration**, without `--allow-motion`. Use a fresh private output directory and a bounded ASCII run ID, for example `python -m g2_local.real_train learner --run-id SESSION_ID --config /absolute/path/final-train.json --output /private/runs/learner-SESSION_ID`. Wait for the `ready` event in `events.jsonl`. The Learner writes periodic `checkpoint.pt` in its output directory at the configured checkpoint interval. Its address must be loopback. A CUDA profile requires working CUDA; do not substitute CPU silently.
4. Start the Actor **without** `--allow-motion` using the same run ID and the **same final configuration file**, but a different new output directory: `python -m g2_local.real_train actor --run-id SESSION_ID --config /absolute/path/final-train.json --output /private/runs/actor-preflight-SESSION_ID`. Verify exit code 2, `motion_not_permitted` in `run_result.json`, and a `run_manifest.json` written before any HID or GDK import. Do not reuse that output directory.
5. Start the Actor with `--allow-motion`, `--context /absolute/path/context.json`, and `--hid-device /dev/...`, plus the same run ID and same final configuration file, using a fresh private output directory. The CLI flag and approved configuration must both be present; the motion factory still performs live checks.
6. For **each** episode, the upstream vision system physically resets the scene and atomically writes a fresh owned context file with a new episode ID and reset timestamp. The operator presses and releases both SpaceMouse buttons after that reset context arrives. Movement intervenes; fresh neutral input held for the configured interval returns control to policy. Y marks success, F marks failure. A time limit ends without inventing either label. Y/F does **not** move the robot to a reset pose; repeat the upstream physical and visual reset before the next episode.
7. Stop the Actor first. Inspect `actor_stopped` and `run_result.json` and confirm the robot command path has stopped before closing transport. Then stop the Learner, inspect its stop evidence, and finally stop `clock_monitor`. If stop is unconfirmed, use the independent hardware E-stop and treat the run as failed.

For evaluation, use the **same approved `mode: train` configuration file** and a checkpoint from the same run ID and exact configuration hash. The explicit CLI `eval` role selects frozen evaluation; do not edit the configuration or set `mode: eval`, since that changes its hash and invalidates the checkpoint. Invoke `python -m g2_local.real_train eval` with `--checkpoint /private/runs/learner-SESSION_ID/checkpoint.pt`, `--context`, `--hid-device`, and `--allow-motion`, using another fresh output directory. Evaluation loads frozen Actor weights and keeps the same intervention safety path; it has no Learner uplink or optimizer. Assisted successes are excluded from the intervention-free success-rate denominator. Every process gets its own manifest; matching run ID and configuration hash establish identity, while role and output path differ. Never reuse output directories. Raw RGB logging stays off unless the configuration explicitly enables it.
