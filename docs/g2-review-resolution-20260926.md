## 已修改

- 自动复位：现场候选 `auto_reset.enabled=false`。保留保持夹持、+Z 5 cm 再返回的实现，待现场路径确认后再启用。**2026-09-27 更正：候选配置绝对 Z 上限实际已从 0.9389 改为 0.965 m，原文“不扩大范围”不准确；本次未找到该变更的现场批准记录，须确认后才能用于真机训练。关闭自动复位不豁免普通动作的工作空间约束。**
- β 初始化：默认至少 **20 个经完整性校验的导入示范回合**，人工 Replay 当前至少 **256 条样本**，才开始 500 步预训练。在线接管片段不算完整示范。导入去重、checkpoint 保存/恢复清单。配置项 `beta_min_demo_episodes`、`beta_min_human_transitions` 可显式调整；文件加载要求正整数，样本门槛不超过容量。门槛不足不进行 Actor/λ 更新，CLI 不误报预训练完成。
- 动作原点：仍用策略前驱，二次位姿差超过候选 `policy_position_drift_m=0.005` / `policy_rotation_drift_rad=0.02` 时拒绝并停止，需有效观测及显式恢复，不自动重试。成功步记录差值，时间门限未放宽。
- 暂存数据：退出时未确认交付的 pending transition 记录 `pending_transition_discarded`，包含 ID、数量、原因和交付不确定性。不编造标签、不盲目补传。这是丢弃记录，不是恢复队列；硬杀进程/磁盘故障无法保证日志落盘。
- 代码身份：摘要扩展到两个环境子模块的 Python 文件（包括未提交/未跟踪文件）及根目录 Python/启动 shell，schema 升至 2。不是完整文件系统镜像，不覆盖所有非 Python 资源或现场 SDK。旧身份 checkpoint 不可静默恢复。
