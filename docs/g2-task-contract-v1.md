# G2 铰链局部对准与插入：任务 I/O 契约 V1

更新：2026-09-24。此文档冻结软件侧 observation/action 表示；不构成真机运动许可或物理安全标定。

## Observation

| 字段 | V1 契约 |
|---|---|
| `observation.state` | 7 个标量 `[x, y, z, qx, qy, qz, qw]`；左臂 `arm_l_end_link` 相对 `base_link` 的末端位姿；XYZ 单位米，姿态为单位四元数 `xyzw`。这是 7 元素表示的 6DoF 位姿，不是 7DoF。 |
| `observation.images.left_wrist` | 左腕 RGB，相机原始帧 HWC `uint8`。 |
| `observation.images.right_aux` | 固定右手辅助视角 RGB，相机原始帧 HWC `uint8`。 |

V1 两路 ROI 均取全帧 `[x0,y0,x1,y1]=[0,0,1280,1056]`，再用 `INTER_AREA` 缩放到 `128×128`；送入网络时转为 CHW `float32` 并除以 255，范围 `[0,1]`。V1 不堆叠历史帧、不加第三视角。全帧压成正方形会改变宽高比；在开始示范采集前，必须确认标准复位画面中孔、铰链和末端在 128×128 下仍可辨认。若需改窄 ROI 或改分辨率，应先形成新配置/数据版本，再采示范，不能混用旧新输入。

2026-09-24 只读采得一组当前双相机帧，保存于 `runtime/task_contract_view_20260924/`。该帧证明 RGB/分辨率链路可读，但不是已确认的标准复位帧，不能据此声称孔/铰链在 128×128 下可辨认；全帧 ROI 先作为统一 V1 基线，示范采集前仍需在标准复位状态检查可见性。

状态不额外拼入未经验证的孔位/目标位姿。视觉复位来源、抓取条件、实际冰箱相对名义位置变化和末端复位扰动作为逐回合上下文记录，不冒充当前传感器状态，也不由训练进程物理移动冰箱。

## Action 与 SpaceMouse

策略及人工提案均为 6 个归一化分量 `u∈[-1,1]^6`：

| 分量 | 语义 | V1 物理映射候选 |
|---|---|---|
| `u[0:3]` | `base_link` XYZ 平移增量 | 每轴 `0.0015 m` × 归一化动作 |
| `u[3:6]` | `base_link` 旋转向量增量 `[rx,ry,rz]`，通过旋转向量组合姿态，不是直接相加的欧拉 RPY | 每轴 `0.026 rad` × 归一化动作 |

夹爪固定闭合，不进入动作向量。SpaceMouse 映射为 `axis_map=(-2,-1,-3,-5,-4,-6)`、左键索引 0：不按左键只启用原生平移通道控制 XYZ；按住左键同时启用原生旋转通道控制绕 base_link X/Y/Z 的旋转向量分量，XYZ 仍可同时移动。微动命令里的旧三轴参数 `-2,-1,-3` 会补齐为上述六轴；正式训练配置必须显式列出六轴。这是输入映射约定，不代表物理正负方向、尺度或六轴并行动作已现场验收。

上述 1.5 mm 和 0.026 rad 是当前只读配置中的 V1 算法起始尺度，不是已批准的机器人单步安全上限。须在空夹爪、明确工作空间和停止措施后低速现场验收；如需改变尺度，更新配置版本并用对应版本采集/标识示范数据。当前配置仍为 `requested_motion=false`、`commissioning.profile=unapproved`。

## 回合标签与域随机化记录

- 操作者按 `Y` 标记成功，按 `F` 标记失败；标签来源为人工。当前配置起始奖励为成功 `+10`、失败 `-1`、普通步 `-0.05`；这是可调训练参数，不是视觉/力觉自动判据。
- 初始位姿不是固定点：上游视觉完成接近孔上方后，操作者按左右键确认新回合。训练策略只处理局部对准和插入。
- 用户提出的“约 5 cm 冰箱位置变化”用于域随机化设计；每回合必须记录实际移动向量及坐标系/来源。当前配置中的 `target_xy_range_m=0.05` 是每个 XY 分量的校验界限，不等价于“位移模长最多 5 cm”，也不驱动实际复位；方向/距离口径尚待现场冻结。禁止用随机生成的标签代替实际场景移动记录。
- 配置中的末端复位扰动 `±3 mm`、`±0.5°` 也只是候选范围；必须和上游视觉实际提供的 reset/context 对上后才能作为采集范围。

## 绑定与未决现场项

仍须完成：标准复位状态下的图像可辨识性确认；实际 fridge offset 的测量坐标与 5 cm 定义；动作尺度与真实工作空间低速验收；软件停止、租约到期和硬件急停停止时间/距离验收。配置文件里的 workspace 数值不是现场测量结果，不得用于运动授权。
